Вариант 08. Кафе
Задание 1

Ввести n (1..30) заказов. Для каждого заказа в цикле for ввести количество блюд (1..10) и цену одного блюда (1..100). Если сумма заказа больше 300, уменьшить её на 15%; если сумма не больше 300 — скидки нет. Вывести цену каждого заказа, общую выручку и количество заказов со скидкой.
Задание 2

Принимать целые положительные чаевые до -1 через while. Остальные неположительные значения (кроме -1) игнорировать. Определить общую сумму чаевых, максимальные чаевые и количество раз, когда новый корректный ввод строго превышал максимум всех предыдущих корректных вводов. Первый корректный ввод считать первым рекордом.
Задание 3

Ввести бюджет B (8..200). Через do-while запрашивать число гостей g (1..15), пока стоимость набора из одного обеда по 8 для каждого гостя не будет укладываться в B. Для каждого неверного количества или дорогого заказа выводить причину отказа. После успешного ввода вывести общую стоимость и сдачу.
Задание 4

Ввести n (3..9). Вложенными циклами вывести числовой треугольник: в строке i печатать i чисел, каждое равно i·j (j от 1 до i). После каждой строки вывести через символ | сумму чисел этой строки. Затем вывести общую сумму всех напечатанных чисел.
